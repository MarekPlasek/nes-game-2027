The streets of district Tau have been riddled with a black market of bootleg robot parts and components! It's up to you to investigate nefarious activities rummaging around town and find the truth about these dealers. But who is truly behind this underground economy?

[Green arrow perpetually going down with heading "Download"]
---

The game will be available for download both on [itch.io](https://crystal-nux.itch.io/tornus-extas) and here in the releases section. Emulator compatibility should be universal. However, **PAL hardware should be used when playing on an original NES**.

[Spinning NES controller with heading "Controls"]
---

[NES controller with small icons and lines pointing from them to the various buttons]

- **A** - Jump
- **B** - Attack
- **D-Pad Left/Right** - Move
- **D-Pad Down** - Dash
- **D-Pad Up** - Interact

[Protag sitting at a computer with heading "Building from source"]
---

The game requires the following development dependencies:

- CC65 V2.18
- GNU Make
- [NEXXT Studio](https://frankengraphics.itch.io/nexxt)
- [FamiStudio](https://famistudio.org/)

The game can then simply be built using `make`...

```sh
make
```

...which will output a binary at `dist/game.nes`.
